## 🚀 Proyectos Destacados

1. **SISROS (En Producción Activa):** Plataforma integral de gestión operativa, finanzas, reportería gerencial y fidelización para centros de detailing y talleres automotrices.
2. **Agente de Voz IA:** Asistente conversacional telefónico para soporte, agendamiento y atención automatizada de clientes.
3. **Automatización de Contenido para Redes:** Pipeline no-code/low-code con Make, Google Sheets e IA para generación y distribución multicanal.
4. **Digitalización de Reservas con Chatbot:** Flujo web interactivo conectado a n8n, OpenAI y Google Calendar.
5. **Agente de Agendamiento WhatsApp:** Automatización conversacional 24/7 para atención, filtrado de prospectos y gestión de citas.
